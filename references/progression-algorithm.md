# Progression Algorithm

本文件定义 Skill 的学习状态、复现频率和难度调整规则。

## 1. 状态字段

每个可追踪项目使用三态：

- `new`：近期首次出现错误，尚未完成验证；
- `unstable`：已经讲解，但仍需要在新语境中复现；
- `mastered`：在不同语境中连续稳定正确。

状态必须基于显式记录，不得凭模型印象判断。

## 2. 状态转换

### new → unstable

首次出错并完成讲解后进入 `unstable`。

### unstable → mastered

满足以下条件：

- 在至少 3 次不同语境的复现中连续正确；
- 其中至少 1 次不是紧接讲解后的即时重复。

### mastered → unstable

如果之后在真实训练中再次出错，立即降回 `unstable`，并清零连续正确次数。

## 3. 复现间隔

按“训练轮次”而不是自然日计算，避免聊天频率不同造成混乱。

### new / unstable

- 第一次错误后：未来 1–3 轮内必须复现 1 次；
- 第一次复现正确：再间隔 2–4 轮复现；
- 第二次连续正确：再间隔 4–7 轮复现；
- 第三次连续正确：可转为 `mastered`。

### mastered

- 进入 `mastered` 后，建议在 8–12 轮后做一次低频抽查；
- 若正确，后续只偶尔自然复现；
- 若错误，立即降级为 `unstable`。

## 4. 每轮复现上限

一组 3–4 个长难句中：

- 最多 2 个句子主要服务于旧错误复现；
- 至少 1 个句子包含新的正常考研语言现象；
- 避免为了复习把句子写得不自然。

## 5. 诊断维度与选材维度

本节是诊断维度与选材难度维度的唯一来源。

- 诊断维度属于输出侧：观察学习者在翻译或写作中表现出的能力；
- 选材维度属于输入侧：根据诊断结果决定下一轮增加、保持或降低哪些难点。

两者按下表对应：

| 输出侧诊断维度 | 输入侧选材维度 |
| --- | --- |
| 主干识别 | 句子长度、长距离主谓关系、长距离修饰 |
| 从句与非谓语识别 | 从句嵌套、非谓语复杂度、多层后置修饰 |
| 语境词义判断 | 熟词僻义、抽象表达与词汇负荷 |
| 固定搭配识别 | 固定搭配的数量与隐蔽程度 |
| 逻辑关系判断 | 逻辑关系的复杂度与隐蔽程度 |
| 中文重组能力 | 被动结构、抽象名词结构及需要调整语序的表达 |
| 写作语法稳定性 | 写作任务中的句式与语法复杂度 |

选材时只调整与当前诊断结果对应的输入维度。其他文件应引用本节，不得另行维护同类清单。

## 6. 难度升级

满足以下任一条件时，可小幅提高难度：

1. 连续 2 轮中至少 75% 句子无重大 `[结构]` / `[逻辑]` 错误，且没有出现明显整体误译；
2. 同一目标错误点连续 3 次在不同语境中正确处理；
3. 用户主动要求提高难度。

每次只提高与诊断结果对应的 1–2 个输入维度，不得同时大幅增加句长、词汇难度和句法复杂度。

## 7. 难度降级或保持

如果一轮中：

- 超过 50% 句子出现重大结构或逻辑错误；或
- 同一目标点连续 2 次复现仍错误；或
- 用户明显只能靠猜测完成句子；

则下一轮保持或略降难度，并优先做针对性复现。

## 8. 写作问题的掌握判断

写作类问题不适合只靠一次修改判断掌握。

例如冠词、时态、主谓一致、固定搭配等：

- 至少在 3 次独立写作中未再出现同类错误，才可标记为 `mastered`；
- 若之后再次出现，降回 `unstable`。
