# Error Taxonomy

统一错误标签用于即时批改，并定义这些标签如何映射到长期学习状态中的 `Category`。

## 即时批改标签

### `[结构]`

句子主干、从句关系、修饰对象或非谓语逻辑判断错误。

### `[词义]`

单词在当前语境中的基本词义判断错误。

### `[熟词僻义]`

认识单词，但没有识别其在当前语境中的非常用义。

### `[搭配]`

固定搭配、动词搭配、介词搭配或常见组合识别错误。

### `[逻辑]`

让步、转折、因果、条件、比较、否定、限制等逻辑关系理解错误。

### `[语法]`

在写作或翻译过程中出现语法形式错误。

### `[增译]`

加入了原文没有表达、且上下文不支持的信息。

### `[漏译]`

遗漏了影响原意的重要信息。

### `[中文表达]`

英文基本理解正确，但中文表达存在明显英语腔、生硬词序或不自然搭配。

## 即时标签 → 长期 Category 映射

| 即时批改标签 | 默认长期 Category | 说明 |
|---|---|---|
| `[词义]` | `vocabulary` | 普通语境词义判断错误 |
| `[熟词僻义]` | `vocabulary` | 熟词非常用义识别问题 |
| `[搭配]` | `collocation` | 长难句、翻译或词汇训练中的固定搭配问题 |
| `[结构]` | `structure` | 主干、从句、非谓语、修饰关系等 |
| `[逻辑]` | `logic` | 转折、让步、因果、条件、否定等 |
| `[增译]` | `translation-style` | 翻译准确性与表达控制问题 |
| `[漏译]` | `translation-style` | 翻译信息完整性问题 |
| `[中文表达]` | `translation-style` | 英语腔、中文重组与自然度问题 |
| `[语法]` | `writing-grammar` | 默认用于写作中的语法问题 |

### 上下文覆盖规则

`[搭配]` 根据任务类型映射：

- 长难句 / 翻译 / 词汇训练：`collocation`
- 写作批改：`writing-collocation`

`[语法]` 如果只是翻译理解过程中对原句语法结构判断错误，优先记为 `structure`，而不是 `writing-grammar`。

`writing-organization` 不直接对应上述 9 个即时标签。它用于记录写作中的宏观组织问题，例如：

- 段落结构混乱
- 题目要求完成不完整
- 图表描述顺序不合理
- 论证组织不清

这类项目由写作批改流程直接写入长期状态。

## Primary Category 规则

一个即时错误可以同时带多个标签，但写入 `learning-state.md` 时：

1. 必须选择一个 `Primary Category`；
2. 优先选择最能解释错误根因的类别；
3. 其他相关标签写入 `Notes`，不要为同一错误重复创建多个长期项目；
4. 同类问题在后续轮次必须保持相同映射，除非有明确理由修改。

### 例子

`readily available` 被译成“已经准备好的”：

- 即时标签可以是 `[词义][搭配]`
- 如果问题本质上是没有识别整个固定组合，则 `Primary Category` 记为 `collocation`
- `Notes` 可记录：`[词义][搭配] readily available = 容易获得的`

这样可以避免长期状态表因多标签而重复膨胀。

---

## 使用原则

1. 即时标签用于解释当前错误；
2. Category 用于长期追踪与调度；
3. 标签不用于机械计数；
4. 后续训练应优先复现反复出现的长期项目；
5. 已经连续稳定正确的问题应按照 `progression-algorithm.md` 降低复现频率。
