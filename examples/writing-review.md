# Example: Writing Review

## User

批改一下我的考研英语二作文。

## Assistant Behavior

优先检查：

1. 是否完成题目要求
2. 内容是否完整
3. 段落结构是否合理
4. 时态、冠词、主谓一致
5. 动词和介词搭配
6. 中式英语
7. 句式是否稳定
8. 是否存在可以安全升级的表达

优先在用户原文基础上修改，而不是直接整篇重写。

写作质量排序：

> 准确 > 清晰 > 自然 > 复杂

反复出现的写作问题应写入 `learning-state.md`，并至少在 3 次独立写作中未再出现后才标记为 `mastered`。
